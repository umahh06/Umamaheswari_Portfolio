# Umamaheswari A – Portfolio
React + Vite + Tailwind CSS + Framer Motion.

## Run
    npm install
    npm run dev        # local
    npm run build      # production build in /dist

## Edit content
All text, links and projects live in `src/data.js`.
Put project screenshots in `public/screenshots/` using the file names listed in data.js.
Replace the LinkedIn `#` link and each project's GitHub URL.
Add a 1200x630 `public/og.png` for link previews.
Deploy: push to GitHub, import into Vercel (framework: Vite).
